# 2026-07-10

## 컨벤션/스펙 동기화 문제와 MCP 도입 검토

* 문제: 원격 저장소에 컨벤션 관련 변경사항이 반영되었으나 로컬에서 pull을 받지 않아 `.claude`에 동기화된 스펙 정의/컨벤션 폴더가 최신 상태로 갱신되지 않음

    * 결과적으로 오래된 컨벤션 기준으로 구현이 진행되어 스펙과 어긋나는 결과물 발생
    * 근본 원인: 컨벤션/스펙 문서가 로컬 파일 동기화(git pull)에 의존하는 구조라 최신성 보장이 어려움

* 개선 방향: MCP를 활용한 정보 소스 분리 검토

    * **변하지 않는 지침**: 컨텍스트 파일(`.claude` 등)로 계속 관리 — 원칙, 아키텍처 방향 등 안정적인 내용
    * **자주 변하는 컨벤션/제품 스펙**: 별도 MCP 서버에서 운영하여 항상 최신 상태로 조회 가능하도록 구성
    * 로컬 파일 동기화 지연으로 인한 컨벤션 불일치 문제를 구조적으로 해소하는 것이 목표

* 결론: 변경 빈도에 따라 지식 소스를 분리(정적 컨텍스트 파일 vs 동적 MCP 서버)하면 로컬 동기화 누락이 있어도 최신 스펙을 참조할 수 있어 구현 신뢰도를 높일 수 있음
